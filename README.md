# iron-wake 🔔

> Telegram-бот: торговый ассистент по 16 бессрочным фьючерсам BingX — VSA-контекст
> и сигналы ложного пробоя Spring/Upthrust с ценой лимитной заявки.

## Что это

**Торговый ассистент (VSA + Spring)** по 16 фьючерсам BingX (14 крипто-пар, золото, нефть Brent
— везде настоящий биржевой объём и стакан):

1. **Контекст** — тренд D1, сильные/слабые уровни, зоны ликвидности по объёму, стакан (DOM).
2. **Сигналы** — авто-поиск паттернов **Spring** (лонг) и **Upthrust** (шорт): цена ЛИМИТНОЙ
   заявки, стоп, цель. Бот сам ведёт сигнал: исполнилась ли заявка, а потом — цель или стоп.
3. **Журнал сделок** — записывается свободным текстом, бот доводит сделку до цели или стопа.

Это подсказки для решений, не авто-торговля. Простые алерты «касание уровня» убраны
20 августа 2026.

## Команды

| Команда | Что делает |
|---|---|
| `/start`, `/help`, `/about`, `/privacy` | базовое меню и справка |
| `/analyze [код]` | расклад глазами движка: пять условий и чего не хватает до сигнала |
| `/subscribe` | подписка на торговые сигналы по инструменту |
| `/signals`, `/stats` | последние сигналы / сводная статистика (винрейт, итог в R) |
| `/trades` | журнал сделок |
| `/settings` | строгость отбора: два ATR-фильтра |
| `/unsubscribe`, `/myid`, `/pay`, `/broadcast` | прочее (последняя — для админа) |

## Стек

Python · aiogram 3 · SQLite · APScheduler · CCXT + pandas/numpy (фьючерсы BingX) ·
yfinance (только журнал сделок по своей паре) · OpenRouter (LLM).

## Как запустить

```bash
pip install -r requirements.txt
cp .env.example .env          # заполни TELEGRAM_BOT_TOKEN, OPENROUTER_API_KEY и др.
python bot.py
```

`bot.db` и `settings.json` создаются автоматически. Тесты движка:

```bash
python tests/test_engine.py
```

**Важно про данные движка:** котировки берутся с публичных эндпоинтов **Kraken** через CCXT
(API-ключи не нужны). Kraken даёт и крипту (BTC/ETH/SOL/TON), и форекс (EUR/USD, GBP/USD, AUD/USD,
USD/CAD, USD/JPY) с реальным объёмом и **не блокирует РФ** — поэтому прокси для движка не нужен.
`CCXT_PROXY` оставлен в коде на случай возврата биржи с гео-блоком. Подробнее о деплое —
[DEPLOY.md](DEPLOY.md), об архитектуре — [CLAUDE.md](CLAUDE.md).
