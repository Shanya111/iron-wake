## Описание (шапка старого CLAUDE.md)
# iron-wake

Telegram-бот — торговый ассистент по бессрочным фьючерсам BingX (крипта, золото, нефть,
валютные пары).

## Стек
- Python + aiogram 3 (FSM, inline-кнопки)
- SQLite через database.py
- APScheduler (`AsyncIOScheduler`) — фоновые задачи движка (планировщик один, в `scheduler.py`):
  мониторинг сигналов (5 мин), трекинг исхода сигналов (5 мин), трекинг сделок журнала (5 мин),
  тренд по недельному каналу (5 мин), пробой сильного уровня (5 мин),
  контекстный анализ (1 час)
- **Источник данных ровно один — биржа BingX.** Yahoo Finance (yfinance) убран из бота
  целиком 26 августа 2026 вместе с полем `ticker` в реестре и ветками `data_source ==
  "yahoo"`. Причина — в разделе «Yahoo убран»
- **CCXT + pandas/numpy** — биржевые OHLCV-свечи и стакан с настоящим объёмом:
  **бессрочные фьючерсы BingX** (тип `swap`), 21 инструмент реестра, и все 21 в движке
- OpenRouter API → модель из `OPENROUTER_MODEL` — свободный текст + гибридный AI-разбор `/analyze`
  + **NL-роутер команд** (текст словами → действие бота) + комментарий к авто-сигналу (см. `llm.py`)

## Структура файлов

```
iron-wake/
├── bot.py              — точка входа, обработчики aiogram, отчёт /analyze,
│                         NL-роутер команд из свободного текста + журнал сделок (/trades)
├── alerts.py           — алерты «касание уровня»: правило срабатывания (hit/side_of/
│                         window_from_candles) — чистые функции, тестируются без сети
├── llm.py              — слой OpenRouter: ask_openrouter (чат, /analyze), classify_intent
│                         (NL-роутер: текст → действие), comment_on_signal (комментарий к сигналу)
├── database.py         — только SQLite: init_db(), CRUD уровней/сигналов/подписок/
│                         настроек, алерты, журнал сделок. Котировок тут больше нет
├── instruments.py      — реестр инструментов (имя, точность, ccxt-символ BingX),
│                         fmt/infer_decimals/resolve/engine_codes/data_source/ccxt_symbol
├── config.py           — все пороги/окна/интервалы движка; через /settings крутятся ровно
│                         два ключа (MAX_ENTRY_DIST_ATR, MAX_RISK_ATR), остальное — константы
├── data_fetcher.py     — загрузка биржевых свечей и стакана (DOM) через CCXT (async) +
│                         TTL-кеш + find_symbol (поиск контракта по вводу человека)
├── analyzer.py         — контекстный анализ: тренд, уровни, зоны ликвидности, стакан,
│                         приоритизация + сборка СКОЛЬЗЯЩЕГО ЧАСА из M15 (rolling_hours)
├── pattern_detector.py — детектор Spring (лонг) и Upthrust (шорт), ATR (_atr) и два фильтра
│                         строгости, цена лимитной заявки (limit_price), исполнение заявки
│                         (evaluate_fill), исход (evaluate_signal), разбор для /analyze (explain)
├── spring_june.py      — ложный пробой по правилам 23 июня (в бою с 15.09.2026): те же
│                         detect_spring / detect_upthrust / explain, чистые функции
├── trend.py            — стратегия №4, тренд по недельному каналу: чистые функции
│                         channels / step / snapshot (без сети и базы)
├── breakout.py         — стратегия №5, пробой сильного уровня (в бою с 22.09.2026 по
│                         крипте, золоту и нефти; по валюте молчит): detect / outcome /
│                         result_r, чистые функции
├── ict.py              — стратегия №6, ICT на часовиках (в бою с 18.09.2026, вместо
│                         тренда; на M15 работала первый день):
│                         свип ликвидности → разрыв (FVG) → слом структуры; detect /
│                         outcome / result_r и векторный atr_series, чистые функции
├── scheduler.py        — фоновые задачи (единственный планировщик) + engine_candles
│                         (свечи, по которым решает движок): run_analysis (1ч) +
│                         monitor_signals (5м) + track_signals (5м) + track_trades (5м) +
│                         check_alerts (5м, алерты по минутным свечам биржи) +
│                         monitor_trend (5м, стратегия №4) и trend_overview (/trend) +
│                         monitor_ict (5м, стратегия №6) и ict_overview (/ict)
├── tests/test_engine.py— юнит-тесты аналитики и паттернов на синтетических свечах
├── bot.db              — SQLite-база данных (в .gitignore, создаётся автоматически)
├── settings.json       — общие значения двух ATR-фильтров от /settings (в .gitignore)
├── system_prompt.md    — системный промпт для LLM (читается при старте бота)
├── .env                — секреты: TELEGRAM_BOT_TOKEN, OPENROUTER_API_KEY, ADMIN_ID, CCXT_PROXY
├── .env.example        — пример переменных окружения (без значений)
├── requirements.txt    — зависимости для деплоя
└── схема.md            — схема текущего функционала бота
```

## Принципы
- Простой и читаемый код — всё должно быть понятно без знания Python
- Модульная структура — легко добавлять новые пары и метрики
- Комментарии на русском
